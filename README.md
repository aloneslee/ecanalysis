# ecanalysis

`ecanalysis` 是一个面向金融市场分析的 Python 服务内核项目。

项目目标是整合财报、公告、新闻、股票 K 线数据，以及 X、Reddit 等社交平台上的关键意见领袖信息，自动生成结构化、可追踪、可复核的股票分析报告。

## 项目定位

这个项目不是简单的行情展示工具，而是一个“数据采集 -> 数据清洗 -> 分析建模 -> 报告生成”的分析服务内核。

后续可以逐步扩展为：

- 财报与公告解析服务
- 实时或准实时行情数据服务
- 社交媒体情绪与观点追踪服务
- 个股综合分析引擎
- 自动化报告生成服务
- 面向前端、脚本或其他系统调用的 API 服务

## 当前状态

项目目前处于初版规划阶段，仓库内还没有正式业务代码。

现阶段优先目标：

1. 明确项目目录结构
2. 搭建 Python 服务基础骨架
3. 确定数据源接入方式
4. 定义分析报告的数据结构
5. 逐步实现可验证的最小闭环

## 初始架构设想

推荐先按下面的方向演进：

```text
ecanalysis/
├── app/                    # Python 服务核心代码
│   ├── api/                # API 接口层
│   ├── core/               # 配置、日志、通用能力
│   ├── data_sources/       # 财报、行情、社交平台等数据源接入
│   ├── analyzers/          # 分析逻辑
│   ├── reports/            # 报告生成逻辑
│   └── schemas/            # 数据结构定义
├── docs/                   # 项目使用文档
├── tests/                  # 测试代码
├── README.md               # 项目说明
└── LICENSE                 # 开源许可
```

这个结构只是初始建议，后续会根据真实功能逐步调整，避免一开始设计得太复杂。

## 数据范围

计划支持的数据类型包括：

- 公司财报：年报、季报、财务指标
- 公司公告：重大事项、回购、增发、并购等
- 市场行情：日 K、分钟 K、成交量、涨跌幅
- 新闻信息：宏观、行业、公司相关新闻
- 社交平台：X、Reddit 等平台的大 V 发言、讨论热度、情绪变化

## 报告目标

最终生成的分析报告应尽量包含：

- 个股基本信息
- 财务表现摘要
- 估值与成长性分析
- 近期行情变化
- 新闻与公告影响
- 社交平台观点摘要
- 主要风险提示
- 可追踪的数据来源
- 明确的结论与置信度说明

## 开发约定

- 项目服务内核使用 Python 实现
- 本地环境优先使用 `.venv` 或 `venv`
- 新功能尽量先完成最小可用版本，再逐步扩展
- 代码修改保持精准，不做无关重构
- 重要功能需要同步更新 `docs/` 目录下的使用文档
- 涉及金融分析结论时，需要保留数据来源和风险提示

## 风险说明

本项目生成的内容只用于辅助研究和分析，不构成任何投资建议。金融数据可能存在延迟、缺失或错误，所有结论都需要结合原始数据进行复核。
